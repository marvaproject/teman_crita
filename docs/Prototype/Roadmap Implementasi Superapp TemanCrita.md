# Roadmap Implementasi Superapp TemanCrita

Dokumen ini berisi urutan eksekusi build untuk Flutter app user-facing TemanCrita.

## Fase 1 - Fondasi App

- Setup project Flutter
- Setup `app_colors.dart` dan theme dasar
- Setup routing dasar
- Setup `Splash / Session Gate`
- Setup auth flow
- Setup bottom navigation

## Fase 2 - Auth dan Dashboard

- Build onboarding
- Build login dan register
- Build email verification
- Build forgot password
- Build dashboard utama
- Build mood check-in

## Fase 3 - Matching dan Discovery

- Build AI matching input
- Build hasil matching
- Build detail psikolog
- Build psikolog card reusable
- Build favorite atau save psikolog jika dibutuhkan

## Fase 4 - Trial dan Booking

- Build trial chat 10 menit
- Build booking flow
- Build payment method selection
- Build payment processing
- Build payment success
- Build payment failed
- Build receipt / transaction detail

## Fase 5 - Session dan Aftercare

- Build upcoming session detail
- Build session reminder / alert
- Build session summary / aftercare
- Build reschedule flow
- Build cancel flow

## Fase 6 - Self-Help Features

- Build breathing exercise
- Build guided journaling
- Build daily affirmation
- Build AI companion chat
- Build crisis resource center

## Fase 7 - Settings dan Profile

- Build profil
- Build settings
- Build notification settings
- Build account recovery flow
- Build logout flow

## Fase 8 - Notification dan State Recovery

- Build reminder scheduler
- Build crisis alert handling
- Build state persistence untuk draft, timer, dan pending action
- Build offline fallback dasar

## Fase 9 - Polishing

- Review empty state
- Review error state
- Review accessibility
- Review microcopy
- Review animation consistency
- Review responsive behavior
